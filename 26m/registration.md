## Technical requirements

The hands-on sessions run in a ready-made environment on your own computer: JupyterLab with Python and Julia, and a shell, in Docker. You need:

- **A computer** running macOS (Intel or Apple Silicon), Linux, or Windows 10/11 with WSL2
- **Docker**: Docker Desktop on macOS and Windows, Docker Engine or Docker Desktop on Linux
- **16 GB of memory** recommended, and **about 40 GB of free disk**
- **A GitHub account**, to ask for help and to work with your team

Installing Docker needs administrator rights: if you use a computer managed by your institution, ask your IT department early. Docker Desktop is free for personal use, education and small organisations; employees of larger companies may need a paid subscription.

Please set up the environment **before 23 November**, following the [**setup page**](https://mcencini.github.io/mritogetherthon/), so that any problem can be solved before the first day. Help is available in the [**Discussions**](https://github.com/mcencini/mritogetherthon/discussions).
